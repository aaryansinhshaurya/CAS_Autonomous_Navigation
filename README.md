# Control and Visualization of an Android-Based Autonomous Navigation System  
### Control of Autonomous Systems (G18)

## Project Overview
This project implements a smartphone-based autonomous navigation system using **Dead Reckoning (DR)** and **Simultaneous Localization and Mapping (SLAM)**. The system is developed using **Android Studio and Java**, and it performs real-time trajectory estimation and visualization without using any GPS or external location services.

The Dead Reckoning module estimates motion using the phone’s IMU sensors, while SLAM-based localization is achieved through the **ARCore SDK** using visual-inertial fusion.

---

## Technologies Used
- Android Studio
- Java
- Android Sensor APIs
- ARCore SDK
- IMU Sensors (Accelerometer, Gyroscope, Magnetometer)
